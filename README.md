# EcoSort AI: Intelligent Urban Waste Segregation System

EcoSort AI is an AI-driven conceptual solution designed to classify municipal solid waste into recyclable, organic, e-waste, and general waste categories to support **UN SDG 12: Responsible Consumption and Production**.

## Features
- **Waste Categorization**: Uses NLP logic to map waste items to the correct municipal bins (Green/Blue/Black).
- **Recycling Guidance**: Provides actionable steps for safe disposal.
- **SDG Alignment**: Addresses urban waste segregation challenges and reduces landfill contamination.
